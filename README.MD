About the Project

The Akidi Welding & Fabrication website is a digital platform built to establish a professional online presence for the company, showcase its work, communicate its services, and make it easier for prospective clients to get in touch.

The website is designed with a clean interface, responsive layouts, and a user-friendly experience across desktop, tablet, and mobile devices.

Features

- Responsive design for mobile, tablet, and desktop
- Professional company presentation
- Services showcase
- Project and portfolio gallery
- Contact information and inquiry section
- WhatsApp integration for direct communication
- Quote request functionality
- Interactive navigation
- Modern UI and user-friendly layout

Technologies Used

- HTML5 — website structure
- CSS3 — styling, layouts, animations, and responsiveness
- JavaScript — interactivity and dynamic functionality
- Git & GitHub — version control and project hosting
- GitHub Pages — website deployment
